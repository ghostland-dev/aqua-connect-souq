# Aqua Connect Souq

Water resource platform with an interactive map and conservation guides.

## Features

- Leaflet interactive map
- Dashboard
- Education and water-saving guide

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Framer Motion
- Leaflet

## Getting Started

```bash
git clone https://github.com/ghostland-dev/aqua-connect-souq.git
cd aqua-connect-souq
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
